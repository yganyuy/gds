这个项目我是用来制作中文联机游戏用的专门针对于手机上开发或者是在电脑上开发都可以.
这个项目主打的是针对于 新手的教程模板 当然它可以直接用作 中小型游戏开发的模板 因为后续我会给他添加很多由C++贡献出来的模块 还有很多高级功能什么的
对于那些高级功能的模块我统一也会进行封装和介绍后续可能还会在其他平台上发布教程,这个项目将会持续维护.
它与常规中文联机项目模板相比他拥有支持 rpc联机功能的模板. //尽管这代码写的很一般,但它的架构方面我认为可能并不会太差,他其实总体代码我肯定不会让他超过七百行因为这是个教程.
为什么我不用内置的连接节点这其中有一点方面是关于动态创建的不过后续我会兼容引擎内置的联机节点.
而且里面已经配置好了 GDE 你可以直接写C++代码,不过我一般并不建议全用这个模块的代码(因为他编译起来慢的要命),为了保证一定的兼容性我还踩了一个坑其中就是他编译后的代码可以在手机编辑器上正常运行和调用.
后续关于计算和运算方面的功能我全会仍在这个模块里面.
这个项目后续可能会改名因为里面很多的地方是我想针对于创游世界这个平台开发者而兼容出来的模板项目.(为什么要兼容这个下水道平台?这没办法因为我也是从这个平台里面爬出来的)(我只是想为当初的自己提供一些便利)
此项目的所有代码并非只有我一个人完成,我动用了AI,但ai一般处理的功能都是运算方面的,整体架构还是由我自己来配置的.
另外目前我也处于一个学习的状态我并不能保证现在写的代码以后不会变更.
如果你有需要的话,直接套用这个模板就行了它非常适合用来制作类似于创游世界的那种2D平台小游戏(后续我还会专门儿给他整个3D的)
